# DTC source catalogue: where manufacturer fault-code facts can legitimately come from

Date: 2026-11-20. Status: **PARTIAL**. Compiled from the six `dtc-sources-*` notes in `docs/research/deep2/` ([BMW](../research/deep2/dtc-sources-bmw.md), [government](../research/deep2/dtc-sources-government.md), [Mercedes](../research/deep2/dtc-sources-mercedes.md), [open projects](../research/deep2/dtc-sources-open-projects.md), [other brands](../research/deep2/dtc-sources-other-brands.md), [Toyota/Lexus](../research/deep2/dtc-sources-toyota-lexus.md)). **No page was re-fetched for this file.** Licence, robots and size facts are as those notes recorded them (confidence tags kept). Not legal advice. Extends [coverage strategy](dtc-coverage-strategy.md) and [data strategy](data-strategy.md); does not repeat their licence layout or effort tables. Fault text is never copied here.

## 0. Plain-words summary for the owner

1. Nobody publishes a free, clean list of BMW, Mercedes or Toyota fault-code meanings. Six research notes, about 150 sources, same answer.
2. The best legitimate source is the US government's bulletin archive (NHTSA). It is public, covers every brand, and can be read by a script.
3. It tells us which codes show up in real repair bulletins, on which cars. It does not give us a code table. We write our own sentences.
4. The one clean free list is for generic codes (about 9,500, public-domain style). It needs a 50-code spot check first.
5. Everything else is a lead, not a source: forums, hobby sites, small GitHub lists. A person reads them. A script does not.
6. Paid portals, leaked databases and copied manuals are off limits. Anyone who has read them cannot write or review that brand's entries.
7. We have not yet counted how many bulletins name a code. That count is the first job (about half a day) and it re-ranks everything.
8. Plan: 4 weeks, in section 7. Week 1 needs your yes to one bounded download of the government files (already recommended in the coverage strategy, decision 3).
9. Two things to expect: coverage will stay thin for Mercedes and Toyota, and the app will say "no description yet" a lot.
10. Counts here are from the notes. Where a number was never measured, it says so.

## 1. How the ranking works

Score = **P x C x E**, each 1 to 3, our judgement (not measured). P = provenance (3 licence read from file and authorship stated; 2 public or government, no reuse licence, or self-reported licence; 1 unknown origin, copyleft or no licence). C = coverage of manufacturer codes (3 all brands, 2 generic or several brands thin, 1 narrow or structure only). E = ease of automated, rule-abiding reading (3 bulk file or open API, 2 parseable files one by one, 1 blocked or manual). Verdicts: **ingest** (facts only, our own words, evidence id kept), **cross-check** (read to find mistakes or frequency, never copy; for sites that is a person, not a script), **manual-read-only**, **excluded**.

## 6. Rules for automated reading

1. **Automate only five kinds of source:** NHTSA bulk files and PDFs (C01, C02, C07, C13); government open APIs with documented use (C09, C06); open datasets with a licence file read (C03, C04, C08); GitHub raw LICENSE and README reads; our own captures. Everything else is a person at a keyboard.
2. **Read robots.txt and the terms first, every host, every run.** Save a dated copy of the rule text in the ledger. A 403, 404 or gateway answer is **not permission**: 404 on `static.nhtsa.gov` means no stated rules, so the polite defaults below apply; 403 on `www.nhtsa.gov` means rules unknown, so we use only the documented download links and ask NHTSA or counsel if a rule turns up.
3. **A "no AI use" signal means no machine reading at all**, even of facts: `ai-train=no`, named AI crawlers blocked, EU Directive 2019/790 Art. 4 notices, pay-per-crawl gateways. Seen on Bimmerforums, Spoolstreet, PriusChat, Bimmerpost-adjacent hosts, BenzWorld, Opinautos, iFixit.
4. **Rate limits (our rule, est.):** one connection per host, at most one request per second, 500 requests per day per host unless the host states more, stop on any 402, 403 or 429, back off one hour, never retry in a loop. GitHub search: at most 10 calls per minute unauthenticated; prefer raw file reads.
5. **Identify ourselves:** user agent names the project and a project mailbox, not a person.
6. **Never mirror.** Store only the fact record (section 7 fields), the source id, URL, fetch date and a file hash. Raw downloads sit outside the repo in `_raw/`, are never committed, and are deleted after extraction unless counsel allows otherwise. No full page, summary text, table or narrative in any pack, doc or log. Extracted strings longer than 300 characters are flagged and dropped.
7. **Personal data:** NHTSA complaints give counts only; drop city, state, dealer, VIN fragment and free text before storage.
8. **Bulk downloads need the owner's yes** (strategy decision 3: about 60 bulletins for BMW, Mercedes, Toyota; a second bounded set for Ford, Honda, Hyundai/Kia, GM needs its own yes).
9. **Cite in this form, always:** bulletin: "<OEM>, <topic or bulletin number> v<n>, <date>, via NHTSA file <MC-id>, accessed <date>". Flat-file row: "NHTSA manufacturer communications file, NHTSA ID <id>, accessed <date>". Investigation: "NHTSA investigation file <PEnnnnn>, bookmark <label>, accessed <date>". Forum fact: "<site> thread <id>, <date>, one owner report: code <x> on <model, year>" with no quote. Open set: "<repo>, commit <sha>, <licence>". Regulation: "13 CCR 1968.2" or "Reg. (EU) 2018/858, Art. 61(1)".
10. **Tainted reader:** anyone who read a paid portal, leaked file or copied manual for brand X does not author or review X entries (honesty declaration; counsel to rate its value).
11. **Stop rule:** if NHTSA or any host blocks us, asks us to stop, or a bulletin notice conflicts with facts-only use, pause that source and escalate to counsel. Recheck robots on the first of each month.
