Phase 0 · research and design

OpenDiag

Free, open-source car diagnostics and coding. An independent alternative to paywalled dealer tools, built from public standards and community data.

GitHub Roadmap

Read faults

Fault codes, freeze frame and plain-English explanations, from basic OBD-II up to every module.

Live data

Sensor readings, readiness checks and service resets through cheap adapters.

Safe coding

Backup first, preview the change, verify after, roll back on any mismatch.

Open data

Community data packs with sources and licenses. No leaked files, ever.

Roadmap

  1. OBD-II reader and vehicle simulator
  2. BMW module scan and fault codes
  3. Live data and service resets
  4. Read-only coding backup and inspect
  5. Gated coding writes on a small set of cars
  6. Toyota/Lexus, then Mercedes-Benz

Safety

Some things are blocked by design: airbag changes, immobilizer bypass, odometer edits and hiding emissions faults in the ECU.

Apache-2.0. Not affiliated with BMW, Mercedes-Benz, Toyota or Lexus. Use at your own risk.
